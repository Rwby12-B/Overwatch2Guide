# /public/images/heroes/full/

**Larger image** shown on the hero's own detail page header and the homepage
carousel's centre hero. Used by `HeroPhoto` with `variant="bust"`. This is a
SEPARATE slot from `icons/` — you can use a more detailed image here even if
you don't add one to `icons/`, and vice versa.

- Filename = hero id, e.g. `tracer.jpg`.
- Format: `.jpg` tried first, then `.jpeg`, `.png`, `.webp`.
- Size: square works best (the header box is square), 512x512px or larger
  recommended since this displays bigger than the grid icon. 256x256 also
  works, just less sharp at large display size.
- Optional per hero — missing ones fall back to the generated full artwork.
