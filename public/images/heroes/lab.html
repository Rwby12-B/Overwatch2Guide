      F.NSM231 INFORMATION SECURITY

      WEEK I — LABORATORY / PRACTICAL WORK

      Preparing and Configuring the Virtual Laboratory Environment

      Виртуал лабораторийн орчин бэлтгэх ба тохируулах

      Student practical guide • English + Монгол тайлбар

      1. Lab Overview / Лабораторийн ажлын танилцуулга

      English: In this laboratory, you will prepare an isolated virtual environment for the cybersecurity activities

      used later in the course. You will verify the virtual machine, network configuration, basic system

      information, and a safe restore point.

      Монгол: Энэ лабораторийн ажлаар хичээлийн дараагийн кибер аюулгүй байдлын дадлагад ашиглах

      тусгаарлагдсан виртуал орчныг бэлтгэнэ. Виртуал машин, сүлжээний тохиргоо, системийн үндсэн

      мэдээлэл болон аюулгүй сэргээх цэгийг шалгана.

      2. Connection to the Course / Хичээлтэй холбогдох нь

      Course element / Хичээлийн хэсэг Week I alignment / I долоо хоногийн уялдаа

      Lecture Introduction to Information Security / Мэдээллийн аюулгүй

      байдлын танилцуулга

      Laboratory

      Preparing and Configuring the Virtual Laboratory

      Environment / Виртуал лабораторийн орчин бэлтгэх ба

      тохируулах

      Primary CLO CLO 1 — Explain fundamental concepts, principles,

      objectives, and models of information security.

      Practical direction Build a controlled environment before security testing /

      Security testing хийхээс өмнө хяналттай орчин байгуулах

      3. Learning Objectives / Лабораторийн зорилго

      • Identify the components of a virtual cybersecurity laboratory. — Виртуал кибер аюулгүй

      байдлын лабораторийн үндсэн бүрэлдэхүүн хэсгүүдийг тодорхойлох.

      • Create or verify a Kali Linux virtual machine in VirtualBox. — VirtualBox дээр Kali Linux виртуал

      машин үүсгэх эсвэл байгаа машиныг шалгах.

      • Configure an appropriate isolated or controlled network mode for the lab. — Лабораторид

      тохирох тусгаарлагдсан эсвэл хяналттай network mode тохируулах.

      • Verify basic operating-system and network information. — Үйлдлийн систем болон сүлжээний

      үндсэн мэдээллийг шалгах.

      • Create a snapshot or other restore point before practical security experiments. — Security

      experiment хийхийн өмнө snapshot эсвэл сэргээх цэг үүсгэх.

      • Document the configuration and verification results. — Тохиргоо болон шалгалтын үр дүнг

      баримтжуулах.

      4. Safety and Authorization / Аюулгүй ажиллагаа ба зөвшөөрөл

      IMPORTANT / ЧУХАЛ

      English: All security testing, scanning, exploitation, or attack simulation in this course must be performed

      only in authorized and controlled laboratory environments. Do not test against university systems, public

      websites, classmates' devices, or other systems without explicit authorization.

      Монгол: Энэ хичээлийн security testing, scanning, exploitation, attack simulation зэрэг үйлдлийг зөвхөн

      зөвшөөрөлтэй, хяналттай лабораторийн орчинд хийнэ. Их сургуулийн бодит систем, public website,

      бусдын төхөөрөмж болон зөвшөөрөлгүй бусад систем дээр туршилт хийхгүй.

      5. Required Environment and Tools / Шаардлагатай орчин ба

      хэрэгслүүд

      Tool / Хэрэгсэл Purpose / Зориулалт

      VirtualBox Create and manage an isolated virtual machine /

      Тусгаарлагдсан виртуал машин үүсгэх, удирдах

      Kali Linux Security testing and analysis environment / Security testing,

      analysis хийх орчин

      Host computer Windows/Linux/macOS system capable of running the VM /

      Виртуал машин ажиллуулах үндсэн компьютер

      6. Part A — Check the Host Environment / A хэсэг — Үндсэн

      компьютерийг шалгах

      English: Before starting the VM, confirm that VirtualBox is installed and that your computer has enough

      CPU, RAM, and storage for the virtual machine.

      Монгол: Виртуал машиныг асаахаас өмнө VirtualBox суусан эсэх, компьютерийн CPU, RAM, хадгалах

      сан нь виртуал машин ажиллуулахад хангалттай эсэхийг шалгана.

      • Open VirtualBox and locate the Kali Linux VM. — VirtualBox-ийг нээж Kali Linux VM байгаа эсэхийг

      шалга.

      • Check the VM name and status. — VM-ийн нэр болон төлөвийг шалга.

      • Do not change advanced settings unless instructed by the instructor. — Багшийн зааваргүйгээр

      advanced тохиргоог өөрчлөхгүй.

      Evidence / Нотолгоо: Take a screenshot showing the VirtualBox window and the Kali Linux VM.

      7. Part B — Verify VM Hardware Settings / B хэсэг — VM-ийн

      hardware тохиргоог шалгах

      English: Open the VM settings and inspect the assigned memory, processors, virtual disk, and network

      adapter. Record the values you see. Do not maximize resource allocation; the host operating system must

      remain usable.

      Page 3 of 6

      Монгол: VM Settings-ийг нээж оноосон memory, processor, virtual disk, network adapter-ийг шалгаж

      харагдаж буй утгуудыг тэмдэглэнэ. Нөөцийг хэт ихээр VM-д өгөхгүй; үндсэн үйлдлийн систем хэвийн

      ажиллах ёстой.

      Item / Үзүүлэлт Observed value / Таны утга Comment / Тайлбар

      RAM

      CPU

      Virtual disk

      Network adapter

      8. Part C — Start Kali Linux and Verify the System / C хэсэг — Kali

      Linux-ийг асааж шалгах

      English: Start the virtual machine and log in using the credentials provided for your course environment.

      Then open a terminal and collect basic system information.

      Монгол: Виртуал машиныг асааж хичээлийн орчинд өгсөн нэвтрэх мэдээллээр нэвтэрнэ. Дараа нь

      Terminal нээж системийн үндсэн мэдээллийг шалгана.

      whoami

      hostname

      uname -a

      ip addr

      English: These commands help you identify the current user, host name, operating-system/kernel

      information, and network interfaces. You are not attacking anything; you are only verifying your own lab

      machine.

      Монгол: Эдгээр команд нь одоогийн хэрэглэгч, host name, үйлдлийн систем/kernel-ийн мэдээлэл

      болон network interface-үүдийг шалгахад ашиглагдана. Та ямар нэг систем рүү халдахгүй; зөвхөн

      өөрийн лабораторийн VM-ээ шалгаж байна.

      9. Part D — Verify Network Isolation / D хэсэг — Сүлжээний

      тусгаарлалтыг шалгах

      English: Check the VirtualBox network mode configured for the laboratory. The exact mode depends on the

      course environment and instructor instructions. The key requirement is that security experiments must

      remain inside an authorized and controlled environment.

      Монгол: Лабораторийн VirtualBox network mode-ийг шалгана. Яг ямар mode ашиглах нь хичээлийн

      орчин болон багшийн заавраас хамаарна. Гол шаардлага нь security experiment зөвшөөрөлтэй,

      хяналттай орчноос гарахгүй байх явдал.

      • Record the configured adapter mode. — Тохируулсан adapter mode-ийг тэмдэглэх.

      • Record the VM IP address shown by ip addr. — ip addr командаар гарсан VM-ийн IP хаягийг

      тэмдэглэх.

      • Do not scan or probe external networks. — Гадаад сүлжээг scan/probe хийхгүй.
