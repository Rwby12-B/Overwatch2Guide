      ЛАБОРАТОРИЙН ХИЧЭЭЛ No 4

      СЭДЭВ: HTML ДУУ, ВИДЕО, SVG ЗУРАГ

      Зорилго: Энэхүү лабораторийн ажлын зорилго нь HTML5-ийн мультимедиа болон вектор

      графикийн боломжуудыг ашиглан дуу, видео болон SVG график агуулсан, зохион

      байгуулалт сайтай веб хуудас боловсруулах практик чадвар эзэмшүүлэхэд оршино.

      Шаардлагатай багаж хэрэгсэл: VS Code, Дурын орчин үеийн вэб хөтөч (Chrome, Firefox,

      эсвэл Edge)

      HTML5 баримтын бүтцийг зөв зохион байгуулах;

      • <audio> таг ашиглан дуу тоглуулах;

      • <video> таг ашиглан видео тоглуулах;

      • controls, autoplay, muted, loop, poster зэрэг шинж чанаруудыг ойлгох;

      • олон төрлийн мультимедиа файлын эх үүсвэр (<source>) ашиглах;

      • SVG-ийн үндсэн ойлголтыг эзэмших;

      • <svg>, <circle>, <rect>, <line>, <polygon>, <path>, <text> зэрэг элементүүдийг

      ашиглах;

      • SVG-д өнгө, хүрээ, хэмжээ, байрлал тохируулах;

      • SVG ашиглан схем, дүрс, диаграм боловсруулах;

      • мультимедиа контентод accessibility-ийн үндсэн шаардлагыг хэрэгжүүлэх;

      веб хуудасны интерфейсийг хэрэглэгчид ойлгомжтой байдлаар боловсруулах чадвартай

      болно.

      ОНОЛЫН ҮНДЭСЛЭЛ

      1. HTML5 МУЛЬТИМЕДИА

      HTML5 нь нэмэлт plugin ашиглахгүйгээр веб хуудсанд дуу, видео оруулах боломжийг

      олгодог.

      Үндсэн мультимедиа элементүүд:

      • <audio></audio>

      • <video></video>

      Өмнө нь веб хөтөчид multimedia тоглуулахын тулд Flash зэрэг нэмэлт технологи шаарддаг

      байсан бол HTML5-ийн тусламжтайгаар стандарт HTML элементүүдээр мультимедиа

      контентыг шууд ашиглах боломжтой болсон.

      1. HTML <audio> элемент

      <audio> элемент нь веб хуудсанд аудио файл оруулах зориулалттай.

      Үндсэн хэлбэр:

      <audio controls>

      <source src="audio/music.mp3" type="audio/mpeg">

      Энд:

      • audio – аудио элемент;

      • controls – тоглуулах, зогсоох, дууны түвшин зэрэг удирдлагыг харуулна;

      • src – аудио файлын зам;

      • type – файлын MIME төрөл.

      Жишээ:

      <audio controls>

      <source src="audio/sample.mp3" type="audio/mpeg">

      Таны веб хөтөч аудио тоглуулах боломжгүй байна.

      </audio>

      <audio> элементийн түгээмэл шинж чанарууд

      Шинж чанар Үүрэг

      controls Удирдлагын хэсгийг харуулна

      autoplay Автоматаар тоглуулна

      muted Дуугүй эхлүүлнэ

      loop Дууг давтаж тоглуулна

      preload Аудиог урьдчилан ачаална

      Давталттай тоглуулах

      <audio controls loop>

      <source src="audio/music.mp3" type="audio/mpeg">

      </audio>

      Дуугүй автоматаар эхлүүлэх

      <audio autoplay muted>

      <source src="audio/music.mp3" type="audio/mpeg">

      </audio>

      Анхаарах: Орчин үеийн браузерууд хэрэглэгчийн үйлдэлгүйгээр дуу бүхий контентыг

      автоматаар тоглуулахыг хязгаарладаг.

      3. SVG ГЭЖ ЮУ ВЭ?

      SVG (Scalable Vector Graphics) нь веб орчинд вектор график дүрслэхэд ашиглагддаг XML- д суурилсан графикийн стандарт юм.

      SVG-ийн хамгийн чухал давуу тал нь:

      • Хэмжээг өөрчлөхөд чанар алдахгүй.

      PNG, JPG зэрэг растер зураг пикселээс бүрддэг бол SVG нь геометрийн дүрс, координат

      болон математик тодорхойлолтоор дүрслэгдэнэ.

      SVG-г дараах зүйлд өргөн ашигладаг:

      • Logo

      • Icon

      • Диаграм

      • Схем

      • График

      • UI элемент

      • Веб инфографик

      • Техникийн зураглал

      SVG-ийн үндсэн бүтэц:

      <svg width="500" height="300">

      </svg>

      Жишээ нь: Энэ код нь цэнхэр дугуй үүсгэнэ.

      <svg width="500" height="300">

      <circle cx="250" cy="150" r="80" fill="blue">

      </circle> </svg>

      1. SVG <rect> Тэгш өнцөгт үүсгэнэ.

      <svg width="500" height="300">

      <rect x="50" y="50" width="200" height="100" fill="lightblue" stroke="black">

      </rect> </svg>

      Үндсэн шинжүүд:

      • x – эхлэх X координат

      • y – эхлэх Y координат

      • width – өргөн

      • height – өндөр

      • fill – дүүргэлтийн өнгө

      • stroke – хүрээний өнгө

      2. SVG <circle>

      <svg width="500" height="300">

      <circle cx="250" cy="150" r="80" fill="orange" stroke="black" stroke-width="3">

      </circle> </svg>

      • cx – төвийн X координат

      • cy – төвийн Y координат

      • r – радиус

      3. SVG <line> Шулуун шугам үүсгэнэ.

      <svg width="500" height="300">

      <line x1="50" y1="50" x2="450" y2="250" stroke="black" stroke-width="4">

      </line> </svg>

      4. SVG <polygon> Олон өнцөгт үүсгэнэ.

      <svg width="500" height="300">

      <polygon points="250,30 450,250 50,250" fill="yellow" stroke="black" stroke-width="3">

      </polygon>

      </svg>

      Энэ жишээгээр гурвалжин үүснэ.

      5. SVG <text> SVG дотор текст оруулж болно.

      <svg width="600" height="200">

      <text x="100" y="100" font-size="32" fill="black">

      Software Engineering

      </text>

      </svg>
