# /public/images/heroes/icons/

**Mini square icons** shown in the hero grid, search results, filters, and the
homepage orbit ring. Used by `HeroPhoto` with `variant="card"`.

- Filename = hero id, e.g. `tracer.jpg`.
- Format: `.jpg` tried first, then `.jpeg`, `.png`, `.webp`.
- Size: **256x256px** square. This is the small/compact icon — keep it simple
  and readable at ~120px display size (card thumbnails).
- Optional per hero — missing ones fall back to the generated icon artwork.
